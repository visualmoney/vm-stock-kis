`api/account/order_modify.py` 의 `pending_order`. §5.5 가 지목한 13곳 중

멀쩡한 import 를 함수 안에 가둔다.

## 함정

첫 측정은 시스템 파이썬이라 `typing_extensions` 가 없어 전부 실패로 보였다.
`uv run` 으로 다시 재야 순환과 환경 오류가 갈렸다.

패키지 루트 `vmkis/__init__.py` 를 간선에 넣으면 거의 모든 지연 import 가
순환으로 보인다. 서브모듈을 불러올 때 루트 init 은 다시 실행되지 않는다.
측정은 파일을 고친 뒤 `import vmkis` 한 번이 맞다.

프로브가 파일을 덮어 쓰면서 줄바꿈만 바뀐 파일이 네 개 남았다
(`quote.py`, `price.py`, `api/account/order_modify.py`, `day_chart.py`).
내용 diff 는 없어서 되돌렸다.
