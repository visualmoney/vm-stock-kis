# 2026-11-15 - §12 P0 현상태

이슈: [#178](https://github.com/visualmoney/vm-stock-kis/issues/178)

## 측정

P0 두 항목은 #19, #20 에서 이미 닫혀 있었다. 2026-11-15 에 다시 대조해도 살아 있는 문서는 그 결론과 맞다.

- Level 1 가이드는 `docs/user/EXTENDING_API.md` 다. README, USER_GUIDE, INDEX, ARCHITECTURE.md 가 가리킨다. 예제의 `domain="live"` 와 19/s·2/s 는 `__env__.py` 와 같다.
- §11-1 계층 그림은 허브-스포크로 바뀌어 있다 (#146, #171).
- §11-2 모의 한도는 ARCHITECTURE.md 가 2/s 로 적는다. 코드도 `PAPER_API_REQUEST_PER_SECOND = 2`.
- §11-3 `types.py` 는 고급 사용자용, 공개 별칭은 `public_types.py`.
- §11-4 확장 절차는 EXTENDING_API Level 0–3 과 ARCHITECTURE 확장성 절(250–800 LOC)이다.
- §11-5 `ARCHITECTURE_QUALITY_KR.md` 는 `docs/reports/archive/` 에 있고, 앞에 수치 인용 금지 경고가 있다. 예전 경로의 파일은 없다.
- §11-6 `CLAUDE.md` 는 없다. `CODING_STANDARDS.md`, `GIT_WORKFLOW.md`, `DOCUMENTATION_RULES.md` 를 가리키는 살아 있는 문서는 없다.
- §11-7 웹소켓 등록을 빠뜨리면 이벤트가 조용히 드롭된다는 문장이 ARCHITECTURE.md 「새로운 WebSocket 이벤트 추가」 2단계에 있다.

## 어긋난 한 문장

EXTENDING_API 가 `info.py` 를 `HHDFS00000300` 의 `fetch()` 로 적었다. 코드는 `self.call(FOREIGN_PRICE, params=...)` 이고 `response_type` 을 생략한다. `FOREIGN_PRICE.tr_live` 가 `HHDFS00000300` 이다. 기본 응답은 `KisDynamicDict`. `fetch()` 직접 호출이 아니다. 그 문장만 고쳤다.

회귀 테스트는 없다. 문장 하나라서 결함을 되돌리는 확인은 하지 않았다.

## 하지 않은 것

P1, P2. §11 표 본문. `docs/reports/archive/` 안의 상대 링크.
